#  B24-Portal

بوابة إلكترونية متكاملة مخصصة لخدمة وإدارة شؤون طلاب الدفعة، تتيح لهم متابعة الإشعارات، الخدمات، والنتائج الأكاديمية بسهولة، مع لوحة تحكم خاصة للإدارة لإدارة المستخدمين والصلاحيات.

##  التقنيات المستخدمة
* **واجهة المستخدم (Frontend):** HTML5, CSS3, JavaScript (Vanilla JS)
* **القواعد والخدمات (Backend & Database):** Supabase
* **مكتبات مساعدة:** SheetJS (XLSX) لمعالجة ملفات Excel

## المميزات الرئيسية
* تسجيل دخول آمن والتحقق من الأرقام الجامعية للدفعة.
* لوحة تحكم متكاملة للمشرفين والمديرين لإدارة الطلاب والخدمات.
* نظام لرفع وعرض النتائج الدراسية ( جداول أو صور ).
* نظام إشعارات وتنبيهات فورية للطلاب.
* دعم الوضع الليلي (Dark Mode) وتصميم متجاوب مع الهواتف الذكية.
